# Libraries Directory

## Required Files

Place the following JAR file in this directory:

### HytaleServer.jar

The Hytale Server JAR file is required to compile this plugin.

**How to obtain**:
1. Install Hytale
2. Locate your Hytale installation directory
3. Find `HytaleServer.jar` in the server files
4. Copy it to this `libraries/` directory

**Typical locations**:
- Windows: `C:\Users\<YourName>\AppData\Roaming\Hytale\install\release\package\game\latest\Server\HytaleServer.jar`
- macOS: `~/Library/Application Support/Hytale/install/release/package/game/latest/Server/HytaleServer.jar`
- Linux: `~/.hytale/install/release/package/game/latest/Server/HytaleServer.jar`

## Note

The JAR file is added to `.gitignore` and will not be committed to the repository.
You must obtain your own copy from your Hytale installation.
